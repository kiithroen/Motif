# Motif 로드맵

## 목표

도레미와 기초 기타 코드만 아는 초보자가 **기초 원리·클래식 해부(7강) → 실전 미션(6강) → 자유 스케치(L1 블록 → L2 변형 체인 → L3 피아노롤)** 사다리를 밟으며 작곡 원리를 귀와 손으로 익히고, 실시간 음악 이론 분석기(향후 Gemini 코치 연동)의 조언을 Before/After 비교 재생으로 체감하는 웹 기반 작곡 학습·스케치 앱을 만든다.

## 지금 상태

- **기초 입문 코스(7강, 랜덤 0%) 완료:** `기초 원리`(화음과 반음 충돌, 뼈대 4음, 계단 연결, 리듬과 쉼표, 코드 색채 바꾸기)와 `클래식 해부·편곡`(베토벤 「환희의 송가」 종지, 파헬벨 「캐논」 8마디 편곡) 7강(`src/data/basics.json`, `src/core/basics.ts`, `src/ui/basicsView.ts`)을 귀 비교 재생(A vs B) + 핵심 원리 카드 + 전용 실습 UI로 구현했다.
- **1단계 · 2단계 완료:** `자유 스케치`(L1 블록 → L2 변형 체인 → L3 피아노롤, 플레이헤드 자동 스크롤, 되돌리기/다시 실행, 이론 코치, WebAudio 엔진, `.mid` 내보내기)와 L1/L2/L3 응용형 `실전 미션`(6강, `src/data/lessons.json`)을 그대로 유지해 3단 학습 모드로 연결했다.
