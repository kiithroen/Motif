# Motif 로드맵

## 목표

도레미와 기초 기타 코드만 아는 초보자가 **기초 입문(4유닛 20강) → 실전 미션(4유닛 20강) → 자유 스케치(L1 블록 → L2 변형 체인 → L3 피아노롤)** 사다리를 밟으며 작곡 원리를 귀와 손으로 익히고, 실시간 음악 이론 분석기(향후 Gemini 코치 연동)의 조언을 Before/After 비교 재생으로 체감하는 웹 기반 작곡 학습·스케치 앱을 만든다.

## 지금 상태

- **기초 입문 20강(4유닛 × 5강, 랜덤 0%) 완료:** 4유닛 코스 목차 대시보드, 완료한 강 랜덤 복습, 이번 강 핵심 배지, A/B 소리 비교와 전용 실습 UI(`src/data/basics.json`, `src/core/basics.ts`, `src/ui/basicsView.ts`)를 통해 화음·뼈대·리듬·클래식 해부(「환희의 송가」, 「작은 별」)·캐논 8마디 편곡까지 단계별로 학습한다.
- **실전 미션 20강(4유닛 × 5강) & 자유 스케치 완료:** L1 블록 설계 → L2 변형 체인 → L3 정밀 편집·이론 코치 → 8마디 완곡·조바꿈까지 20개 미션을 4유닛 목차 및 랜덤 복습 UI(`src/data/lessons.json`, `src/core/lesson.ts`, `src/ui/lessonPanel.ts`)로 연결했고, `자유 스케치` 샌드박스·WebAudio 엔진·`.mid` 내보내기·GitHub Pages 자동 배포까지 완료했다.
