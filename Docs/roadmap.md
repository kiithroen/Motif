# Motif 로드맵

## 목표

도레미와 기초 기타 코드만 아는 초보자가 **블록 -> 변형 체인 -> 음표 피아노롤** 3단 추상화 사다리를 오르내리며 작곡 원리를 귀와 손으로 익히고, 실시간 음악 이론 분석기(향후 Gemini 코치 연동)의 조언을 Before/After 비교 재생으로 바로 체감하는 웹 기반 작곡 학습·스케치 앱을 만든다.

## 지금 상태

- **1단계 완료:** `L1 블록`(진행·그루브·윤곽) → `L2 변형 체인`(6종 변형 카드 + 전/후 비교 + 마디 코드 교체) → `L3 피아노롤`(2옥타브 직접 편집 + PC 건반 연주 + 스케일/코드톤 색 가이드) 3단 추상화 샌드박스와 순수 TS 이론 분석기(`analyzer.ts`, 5종 규칙 + 원클릭 수정안), 절차적 WebAudio 악기 엔진(Karplus-Strong 기타·FM 피아노·베이스·드럼), 표준 `.mid` 내보내기를 구현하고 `typecheck`·Vitest(11개)·Vite 빌드·실브라우저(`1440×900`) 검증까지 마쳤다.

## 단계 계획

### 1단계: 코어 샌드박스 · 이론 코치 · WebAudio 엔진 (완료)
- `L1 블록`(진행·그루브·윤곽) -> `L2 변형 체인`(모달 인터체인지·모티프 반복·싱코페이션·종지 해결·옥타브 리프트·경과음 + 마디 코드 교체) -> `L3 피아노롤`(2옥타브 직접 편집, 스케일/코드톤 가이드, PC 건반 연주)
- 순수 TS 이론 분석기 5종 규칙 + 원클릭 Before/After 수정안 미리듣기
- Karplus-Strong 기타·FM 피아노 기반 룩어헤드 루프 재생 + 표준 MIDI(`.mid`) 내보내기

### 2단계: 듀오링고식 마이크로 작곡 레슨
- 리듬 -> 4코드 감정 변화 -> 코드톤 뼈대 -> 모티프 변주 -> 8마디 완곡 순서의 3분 미션형 커리큘럼
- 빈 캔버스 대신 "어색한 종지 고치기 / 4코드 중 1개 바꾸기" 퍼즐 형태로 구성

### 3단계: Gemini API 코치 연동
- 로컬 이론 분석 리포트 JSON 을 초보자 눈높이 한국어 코칭으로 풀고, 자연어 요청을 L1/L2 블록·변형 패치로 변환해 즉시 비교 재생

### 4단계: 고품질 샘플 보강 및 포팅
- 필요 시 경량 실제 악기 샘플 교체 및 Capacitor 기반 Android/데스크톱 패키징 검토
