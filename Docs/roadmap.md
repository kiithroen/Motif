# Motif 로드맵

## 목표

도레미와 기초 기타 코드만 아는 초보자가 **블록 -> 변형 체인 -> 음표 피아노롤** 3단 추상화 사다리를 오르내리며 작곡 원리를 귀와 손으로 익히고, 실시간 음악 이론 분석기(향후 Gemini 코치 연동)의 조언을 Before/After 비교 재생으로 바로 체감하는 웹 기반 작곡 학습·스케치 앱을 만든다.

## 지금 상태

- **1단계 완료 및 보강:** `L1 블록`(진행·그루브·윤곽) → `L2 변형 체인`(6종 변형 카드 + 전/후 비교 + 마디 코드 교체) → `L3 피아노롤`(2옥타브 직접 편집, 마디별 코드톤 가이드, 음표 길이 선택, 되돌리기/다시 실행, PC 건반 연주) 3단 추상화 샌드박스와 재생 중 부분 DOM 갱신·미리듣기 원본 복원, 순수 TS 이론 분석기(`analyzer.ts`), WebAudio 악기 엔진, `.mid` 내보내기까지 구현 및 검증 완료.
- **2단계 완료:** 듀오링고식 마이크로 작곡 레슨 6종(`src/data/lessons.json`, `src/core/lesson.ts`, `src/ui/lessonPanel.ts`) 구현. 리듬 그루브 → 모달 인터체인지 → 종지 해결 → 마디 첫 박자 코드톤 → 모티프 변주 → 8마디 완곡 순서의 퍼즐형 미션, 실시간 체크리스트 판정, 힌트·초기화, 자유 스케치와 분리된 진행도 저장(`motif_lessons_v1`)까지 연결 완료.
